ENTENDIENDO LAS BASES: COMO PIENSA UNA COMPUTADORA

Programar es darle instrucciones a una computadora para que haga algo.

Es como darle órdenes a un robot: "Suma estos números" "Muestra este mensaje" "Si pasa esto, haz esto otro"

Ejemplo de la vida real:

Imagínate que haces un sándwich: Agarrar pan. Poner jamón. Poner queso. Cerrar pan. Eso es un algoritmo (una lista de pasos).

La computadora no entiende intenciones, solo ejecuta instrucciones exactas en el orden que se le indican.
Llevando la idea a programación:
La computadora NO piensa, solo hace exactamente lo que tú le dices. 

// Usaremos el lenguaje de Programacion Java

System.out.println("Paso 2: Poner jamón");

Usa comillas dobles para los textos y lo mas importante, NO OLVIDES EL PUNTO Y COMA!! .

Este sencillo programa es el primer paso para aprender Java y entender su estructura básica.

CONDICIONALES: CUANDO TU PROGRAMA PIENSA

Los condicionales son estructuras que permiten que un programa tome decisiones.
Funcionan con una lógica simple:
evaluar una condición y, según si se cumple o no, ejecutar ciertas instrucciones.
En otras palabras, un condicional le dice a la computadora: "si pasa esto, haz esto; si no, haz otra cosa".

Ejemplo de la vida real:
Imagina esta situación:
Si tienes dinero, compras comida. Si no tienes dinero, no compras. Aquí hay una decisión basada en una condición, la idea es esta:

Si (condición) entonces
hacer algo
si no
hacer otra cosa

Ejemplo en programación (Java): 
int dinero = 10;

if (dinero > 5) {
    System.out.println("Puedes comprar comida");
 } else {
    System.out.println("No te alcanza");
}

int dinero = 10; Se crea una variable que guarda cuánto dinero tienes if (dinero > 5) Se evalúa la condición: ¿10 es mayor que 5?, Si!
→ Como la condición es verdadera, se ejecuta: "Puedes comprar comida".
else {} solo se ejecuta si la condición es falsa

Operadores importantes:
Operador Simbolo
Mayor que >
Menor que <
Mayor o igual >=
Menor o igual <=
Igual ==
Diferente de !=

Operadores Logicos:

(&&, ||, !) Estos operadores se usan dentro de los condicionales para combinar o modificar condiciones. Piensa que trabajas con respuestas de tipo verdadero o falso.

&&

verdadero && verdadero → verdadero
verdadero && falso → falso
falso && verdadero → falso
falso && falso → falso

||

verdadero || verdadero → verdadero
verdadero || falso → verdadero
falso || verdadero → verdadero
falso || falso → falso

! (Negacion)

Si era falso, se vuelve verdadero y viceversa.


else if (múltiples decisiones)

Se usa cuando tienes varias opciones posibles, pero solo una se ejecuta. 

int nota = 75;

if (nota >= 90) {
    System.out.println("Excelente");
} else if (nota >= 70) {
    System.out.println("Aprobado");
} else if (nota >= 50) {
    System.out.println("Regular");
} else {
    System.out.println("Reprobado");
}

Se evalúa de arriba hacia abajo
Cuando una condición es verdadera, se ejecuta y se detiene
Las demás ya no se revisan

🧠 if anidados (if dentro de otro if)

Se usan cuando necesitas validar algo dentro de otra condición. 

int edad = 20;
boolean pago = true;

if (edad >= 18) {
    if (pago == true) {
        System.out.println("Puede entrar");
    } else {
        System.out.println("Debe pagar");
    }
} else {
    System.out.println("Menor de edad");
}

Primero se evalúa una condición. Si es verdadera, entonces se evalúa otra dentro.

ESTRUCTURAS DE CONTROL: AUTOMATIZA PROCESOS

Las estructuras de control son fundamentales en la programación, ya que permiten controlar el flujo de ejecución de un programa.
Gracias a ellas, es posible repetir instrucciones, tomar decisiones y automatizar procesos.
En esta seccion aprenderás a utilizar los ciclos repetitivos más importantes: for, while y do while, además de comprender el uso de contadores y acumuladores, herramientas esenciales para resolver problemas de manera eficiente.

Ciclo FOR

El ciclo for se utiliza cuando sabemos cuántas veces queremos repetir una instrucción. 

for (inicialización; condición; incremento) {
   // instrucciones
}
Ejemplo Practico

Se desea contar del 1 al 10 usando un blucle for

public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            System.out.println(i);
        }
    }
}
int i = 1 → inicia el contador.
i <= 10 → condición para seguir.
i++ → incrementa en 1.

CICLO WHILE

El ciclo while repite instrucciones mientras una condición sea verdadera. 

while (condición) {
   // instrucciones
}
Ejemplo Prectico

Se desea contar de 1 al 5 usando el bucle while

public class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            System.out.println(i);
            i++;
        }
    } 
}

Explicacion del Ejemplo:

1. Se crea una variable llamada contador con valor 1.
2. El ciclo verifica si contador <= 5.
3. Si se cumple, imprime el número.
4. Luego aumenta el contador con contador++.
Cuando contador llega a 6, la condición ya no se cumple y el ciclo termina.

El programa seguirá ejecutándose mientras i sea menor o igual a 5.

Se usa cuando no sabemos exactamente cuántas veces se repetirá una acción, ya que depende de que una condición se cumpla.
Idea clave: Primero evalúa la condición y, si es verdadera, ejecuta el bloque de instrucciones.
NO OLVIDES ESTO!

Es un error muy comun en los Principiantes "Olvidar actualizar la variable."

Esto esta incorrecto:

int i = 1;

while (i <= 5) {
   System.out.println(i);
}

Esto genera un bucle infinito porque i nunca cambia, lo q podria petar tu pc 😂.

lo correcto es usar la variable i++;

Programacion Orientada a Objetos (POO)
ENTENDIENDO LAS BASES

La Programación Orientada a Objetos (POO) es un paradigma de programación que organiza el software en objetos, los cuales representan entidades del mundo real mediante atributos y comportamientos.

Que es un Objeto?

Un objeto es una instancia de una clase.

Por ejemplo:
Un carro tiene atributos: color, marca, velocidad.
Un carro tiene comportamientos: acelerar, frenar, encender.
En Programacion: 
Carro miCarro = new Carro();

Carro: Clase
miCarro: Objeto


Que es una Clase

Una clase es un molde o plantilla que define las características y comportamientos de un tipo de objeto.
Es como un plano que describe cómo se ve y qué puede hacer un objeto, pero no es el objeto en sí.

Ejemplo:
La clase "Perro" podría tener atributos como "raza", "edad" y "color", y métodos como "ladrar()" o "comer()".
Cuando creas un objeto a partir de esta clase, como "miPerro", ese objeto tendrá sus propios valores para esos atributos y podrá usar los métodos definidos en la clase.
Ejemplo en Java: 
// 1. Definimos la clase "Perro" (El molde)
class Perro {
    // Atributos (Características)
    String raza;
    int edad;
    String color;

    // Métodos (Acciones)
    void ladrar() {
        System.out.println("¡Guau! ¡Guau!");
    }

    void comer() {
        System.out.println("El perro está comiendo sus croquetas.");
    }
}

// 2. Clase principal para ejecutar el programa y crear el objeto
public class Main {
    public static void main(String[] args) {
        
        // Creamos el objeto "miPerro" a partir de la clase "Perro"
        Perro miPerro = new Perro();

        // Le asignamos valores propios a sus atributos
        miPerro.raza = "Labrador";
        miPerro.edad = 3;
        miPerro.color = "Dorado";

        // Mostramos las características del objeto en la consola
        System.out.println("Mi perro es un " + miPerro.raza + " de color " + miPerro.color + " y tiene " + miPerro.edad + " años.");

        // Ponemos al objeto a usar sus métodos
        miPerro.ladrar();
        miPerro.comer();
    }
}
