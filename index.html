📘 ENTENDIENDO LAS BASES: COMO PIENSA UNA COMPUTADORA

Programar es darle instrucciones a una computadora para que haga algo.

Es como darle órdenes a un robot: “Suma estos números” “Muestra este mensaje” “Si pasa esto, haz esto otro”

Ejemplo de la vida real:

Imagínate que haces un sándwich: Agarrar pan. Poner jamón. Poner queso. Cerrar pan. Eso es un algoritmo (una lista de pasos).

La computadora no entiende intenciones, solo ejecuta instrucciones exactas en el orden que se le indican.
Llevando la idea a programación:

La computadora NO piensa, solo hace exactamente lo que tú le dices.

// Usaremos el lenguaje de Programacion Java
System.out.println("Paso 1: Tomar pan");
System.out.println("Paso 2: Poner jamón");
System.out.println("Paso 3: Poner queso");
System.out.println("Paso 4: Cerrar pan");

Errores comunes:
Asegúrate de cerrar correctamente los paréntesis y llaves {}, los usaremos mas adelante
Usa comillas dobles para los textos y lo mas importante, NO OLVIDES EL PUNTO Y COMA!! .


Este sencillo programa es el primer paso para aprender Java y entender su estructura básica.

🧩 VARIABLES: LA MEMORIA DE LA COMPUTADORA

🔁 CONDICIONALES: CUANDO TU PROGRAMA PIENSA

Los condicionales son estructuras que permiten que un programa tome decisiones.
Funcionan con una lógica simple:
evaluar una condición y, según si se cumple o no, ejecutar ciertas instrucciones.
En otras palabras, un condicional le dice a la computadora: “si pasa esto, haz esto; si no, haz otra cosa”.

Ejemplo de la vida real:
Imagina esta situación:
Si tienes dinero, compras comida. Si no tienes dinero, no compras. Aquí hay una decisión basada en una condición.

Ejemplo en programación (Java): 
int dinero = 10;

if (dinero > 5) {
    System.out.println("Puedes comprar comida");
 } else {
    System.out.println("No te alcanza");
}

  • int dinero = 10; Se crea una variable que guarda cuánto dinero tienes
  • if (dinero > 5)
    • Se evalúa la condición: ¿10 es mayor que 5?, Si!
    → Como la condición es verdadera, se ejecuta: "Puedes comprar comida".
  • else {}
    • solo se ejecuta si la condición es falsa

    Operadores importantes:
      Mayor que  >
      Menor que  <
      Mayor o igual  >=
     Menor o igual  <=
     Igual  ==
     Diferente de  !=
